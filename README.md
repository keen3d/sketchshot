# SketchShot 스케치샷 — 윈도우 앱(.exe) 프로젝트 v0.1.2

Tauri 2로 감싼 윈도우 데스크톱 앱입니다. 윈도우에 기본으로 들어 있는 Edge 엔진(WebView2)을 써서
설치 파일이 작고, 펜 필압도 Edge와 똑같이 동작합니다.

## 브라우저 버전과 달라지는 점

- **진짜 저장 창**: Ctrl+S는 윈도우 ‘다른 이름으로 저장’ 창을 띄우고, 한 번 저장한 뒤에는 같은 파일에 바로 덮어씁니다. Ctrl+Shift+S는 다른 이름으로 저장입니다.
- **열기**: Ctrl+O와 ‘열기’ 버튼이 윈도우 파일 열기 창을 씁니다.
- **파일 연결**: 설치하면 `.sketchshot` 파일 아이콘을 더블클릭해서 바로 열 수 있습니다. 앱이 이미 켜져 있으면 새 창을 띄우지 않고 기존 창에서 엽니다.
- **닫기 확인**: 저장하지 않은 변경이 있으면 창을 닫을 때 한 번 묻습니다.
- **창 제목**: 파일 이름과 저장 여부(•)가 창 제목에 표시됩니다.
- **PSD·이미지 내보내기**도 같은 저장 창으로 원하는 위치에 저장합니다.

## 방법 1. GitHub에서 자동으로 만들기 (내 PC에 아무것도 설치하지 않아도 됨)

1. github.com에서 새 저장소를 만들고, 이 폴더의 파일을 폴더 구조 그대로 전부 올립니다.
   `.github` 폴더도 꼭 함께 올려야 합니다(숨김 폴더라 빠뜨리기 쉽습니다).
2. 올리면 저장소의 **Actions** 탭에서 “윈도우 설치 파일 만들기”가 자동으로 시작됩니다.
   처음에는 10~20분 걸리고, 다음부터는 캐시 덕분에 더 빨라집니다.
3. 끝나면 실행 기록을 눌러 아래쪽 **Artifacts**의 `SketchShot-Windows`를 내려받습니다.
   압축을 풀면 `SketchShot_0.1.2_x64-setup.exe`가 들어 있습니다.

Actions 탭에서 **Run workflow** 버튼으로 언제든 다시 만들 수 있습니다.

## 방법 2. 내 PC에서 직접 만들기

필요한 것(처음 한 번만):
1. **Microsoft C++ Build Tools**: Visual Studio Installer에서 “C++를 사용한 데스크톱 개발”
2. **Rust**: https://rustup.rs 에서 설치
3. **Node.js 20 이상**: https://nodejs.org

이 폴더에서:
```
npm install
npm run dev      # 개발 모드로 바로 실행해 보기
npm run build    # 설치 파일 만들기
```
설치 파일은 `src-tauri\target\release\bundle\nsis\` 에 생깁니다.

## 설치할 때 나오는 경고

코드 서명을 하지 않은 프로그램이라 처음 실행할 때 윈도우가 “Windows의 PC 보호” 창을 띄웁니다.
**추가 정보 → 실행**을 누르면 설치됩니다. 팀에 배포할 거라면 코드 서명 인증서를 붙이는 것을 권합니다.
설치는 관리자 권한 없이 현재 사용자 계정에만 됩니다.

## 앱을 고친 뒤 새 버전 만들기

1. 바뀐 앱 파일(claude.ai에서 받은 HTML)을 `src/index.html`에 덮어씁니다.
2. 버전 숫자를 세 곳에서 똑같이 올립니다: `package.json`, `src-tauri/Cargo.toml`, `src-tauri/tauri.conf.json`
3. GitHub에 올리면 새 설치 파일이 만들어집니다. 기존 앱 위에 그대로 설치하면 업데이트됩니다.

## 폴더 구성

- `src/index.html` — 앱 본체 (브라우저 버전과 같은 파일. 윈도우 앱 안에서는 자동으로 저장·열기 창 연동이 켜짐)
- `src-tauri/src/lib.rs` — 파일 읽기·쓰기, 파일 더블클릭 처리
- `src-tauri/tauri.conf.json` — 창 크기, 아이콘, `.sketchshot` 파일 연결, 설치 프로그램 설정
- `src-tauri/capabilities/default.json` — 앱이 쓸 수 있는 기능 목록 (저장·열기 창, 닫기 확인)
- `.github/workflows/build-windows.yml` — GitHub 자동 빌드

## 알아둘 점

- 글꼴(IBM Plex Sans KR, 본명조 등)은 인터넷에서 받아 옵니다. 인터넷이 없으면 맑은 고딕 같은 윈도우 기본 글꼴로 대신 보입니다.
- 자동 저장(이어서 하기)은 브라우저 버전과 따로 보관됩니다.
- 이 프로젝트는 설정과 코드를 검토해서 만들었지만, 만든 환경에서 직접 컴파일해 보지는 못했습니다. 빌드에서 오류가 나면 Actions 로그의 빨간 줄을 그대로 알려 주세요.
